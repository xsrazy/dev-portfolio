# Developer Portfolio

Live site: https://dev.xsrazy.web.id

A single page portfolio of Rahmatul Usra (@xsrazy) showcasing 16 live projects in 7 categories.

## Projects

- Wedding invitations: NikahPee, NikahTube, Wedify, samaWA, Nikah, NikahFix
- Web tools and apps: LinkPass, TikBulk, Micro Tools, CekTag
- Temp mail: TMail
- Store and catalog: myrobs.store, FMCreators Marketplace
- Recipes: Masakan Kekinian
- Developer: GitHub Readme Stats
- Design: ShareCanva

## Features

- Dark and light mode
- Category filter
- A Preview button on every card that opens a floating window showing the live project site inside, with an Open in new tab link and a Close button (Escape key and backdrop click also close it)
- A Visit site link that opens the project in a new tab
- Custom 1200x900 screenshots for 14 projects, with automatic fallback previews for the rest

## Tech

One static HTML file, no build step. Deployed on Vercel at dev.xsrazy.web.id.

## Files

- `index.html`: the whole portfolio page
- `thumbs/`: custom project screenshots
